UPDATED One dialog: manual adds and bulk import share a review list

Header “+ Add” opens the dialog. Typing a search adds rows to the list (“Save & add another” = “Add to list”). “Import file” fills the same list from a CSV: every column the manual form has (name, set, number, type, qty, condition, paid, sealed/graded) is auto-read, matched against the catalog, and filled in with art and live price. Nothing is saved until you press Add N items, and every cell is editable.

AUTOCOMPLETE Type-ahead when adding manually

The search box suggests as you type (after 2 characters, debounced ~150 ms). Cards and sealed are searched together by default, with a Card / Sealed filter. Matching is forgiving: partial words, missing punctuation, set name, and card number (“mega gengar 284”, “151 etb”, “pris evo bb”). Results are grouped, show art, set, number, rarity and current price, and are fully keyboard-driven. Picking one drops it into the review list and returns focus to the search box for the next card.

Behaviors

• Recent & frequent: empty search shows the last 5 items you added.
• Already owned: results you already own show an “Owned ×2” badge, and adding bumps the quantity.
• Empty state: “No matches for ‘xyz’. Add as custom item” (name, set, price entered by hand).
• Source: same catalog the pricing already uses (TCGdex cards, TCGCSV sealed), queried through a server route so keys stay private; results cached for speed.
• Import rows use the same matcher, so a typed “Eevee ex” in a CSV gets the same suggestions in its dropdown.

Direction: header “+ Add” button (A) with a menu for Add card or sealed and Import file, opening one dialog with a shared review list for manual and bulk adds.
